#  Phishing URL Detector

Developed by: Bhumika Shree U 
Domain: Cybersecurity

---

##  Project Overview
This project is a Flask-based web application that detects phishing URLs using rule-based analysis techniques. It evaluates URLs based on multiple security factors and classifies them as Safe, Suspicious, or High Risk.

---

##  Features
- URL risk analysis
- Detection using multiple parameters:
  - URL length
  - IP address usage
  - Suspicious keywords
  - Subdomains
  - Domain age
- Risk score visualization
- Clear classification (Safe / Suspicious / High Risk)
- Explanation of results
- Precaution suggestions for users
- Clean and user-friendly interface

---

##  Technologies Used
- Python
- Flask
- HTML
- CSS

---

## Conclusion
This project helps users identify potentially malicious URLs and promotes cybersecurity awareness by providing detection results along with safety precautions.
